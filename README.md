# Mehdy Mokhtari Portfolio Website

Source code for [mehdymokhtari.ir](https://mehdymokhtari.ir).

## About

This repository contains the exported Patterns Portfolio WordPress block theme and site-specific changes for my portfolio website.

## Structure

- `wp-content/themes/patterns-portfolio/` — WordPress theme files, templates, template parts, patterns, styles, and theme settings.
- `docs/` — Site notes and future setup or deployment instructions.

## Scope

This repository tracks theme source files. It is not a complete backup of the WordPress site. The WordPress database, plugins, and media library may be managed separately.
